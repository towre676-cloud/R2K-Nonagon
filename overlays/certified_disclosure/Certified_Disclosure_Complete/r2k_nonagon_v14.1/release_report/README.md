# Integrated release guide

`Nonagon_Integrated_Release.pdf` is the compact reading guide to the combined mathematical and engineering release. It routes the reader to the complete proofs, explicit acquisition assumptions and replay records rather than reproducing all chapter material.

The PDF is generated by `build_guide.py` from its reviewed content and `release_facts.json`. Its source figures are generated automatically. From this folder, with ReportLab and Matplotlib installed:

```bash
py -3.11 build_guide.py
```

The script writes the PDF into this folder. Use `--output /absolute/path/report.pdf` to select another destination; it also retains a copy here. `release_facts.json` records the fresh campaign statistics included in the guide. Full campaign records remain under `part_IX/load_planning`, `part_IX/dynamic_acquisition` and `cross_checks`.

The independent replay command is run from the release root:

```bash
py -3.11 replay_all.py
```

The guide reports circuit-simulator and synthetic calibration evidence. No physical apparatus was measured for this release.
