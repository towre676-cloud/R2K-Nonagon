# Recoverability and robustness: exact scope

Let y=H theta+epsilon and z=T theta, with no prior restriction on theta. Then z is uniquely determined by noiseless y if and only if ker(H) is contained in ker(T). Proof: any two observationally indistinguishable parameters differ by a vector in ker(H). The inclusion says their target difference vanishes. Conversely, a vector in ker(H) with nonzero target image gives an explicit indistinguishable pair. This is equivalent to existence of a linear decoder D with DH=T, by factoring T through the image of H.

For covariance R positive definite, every unbiased linear target decoder has covariance D R D^T. When H has full column rank, GLS gives D=T(H^T R^-1 H)^-1 H^T R^-1 and target covariance T(H^T R^-1 H)^-1 T^T. Square-root QR is used for computation to avoid squaring the condition number through normal equations. Gaussian noise makes this exact for the linear model. For bounded whitened noise ||R^-1/2 epsilon||<=eta, deterministic target error is at most eta ||D R^1/2||_2. These are separate stochastic and deterministic assertions.

For nonlinear response f(theta), apply the kernel test to its derivative for infinitesimal target sensitivity. Full column rank gives local parameter identifiability through a locally invertible submap. Pointwise derivative-kernel inclusion for a lower-dimensional target is not by itself a global nonlinear factorization theorem. Finite measurement fibers must be examined separately.

The physical measurement is e_0^T (K+Theta)^-1 e_0. With K=sum_e w_e b_e b_e^T, its derivative with respect to log w_e is -w_e (b_e^T (K+Theta)^-1 e_0)^2. An effective resistance u^T K^-1 u has log-weight derivative -w_e (b_e^T K^-1 u)^2. The study uses these derivatives at nominal parameters for design and at actual frozen parameters only for evaluation.

For independent row noise with variance s2 and existing parameter covariance C, adding row a updates covariance to C-C a^T a C/(s2+a C a^T). Target variance reduction is ||T C a^T||^2/(s2+a C a^T). Full-parameter A-optimality uses T=I. D-optimality maximizes log(1+a C a^T/s2). These rank-one formulas justify the implemented forward scores; they do not prove the chosen fixed-seed greedy panel is globally optimal.

For correlated readings, augment theta with bias variables b: y=H theta+Z b+e, with Cov(e)=0.5 I and Cov(b)=0.25 I. A square-root prior constraint 2I is applied only to b. Marginalization yields R=0.5 I+0.25 ZZ^T. Here Z includes the all-ones common-reference column and one active group column per row. This identity supports the correlated-noise selector and GLS decoder. It does not confer robustness to arbitrary bias distributions or covariance misspecification.

For two fixed candidate responses mu0 and mu1, a single observation with independent Gaussian noise sigma^2 h0^2 and equal candidate priors has optimal error probability Phi(-|mu0-mu1|/(2 sigma h0)). The branch experiment reports this one-reading, two-known-candidate decision error. It does not include candidate-estimation uncertainty, unknown third branches, or the full adaptive transcript's conditional noise distribution. Absolute disagreement is optimal here because every candidate reading has equal marginal noise variance. The original relative-disagreement rule solves a different normalized design criterion.

Recoverability after every one-channel loss requires the kernel inclusion for every row-deleted matrix. Recoverability under q arbitrary channel corruptions requires the corresponding inclusion after removal of every set of up to 2q channels in this unconstrained linear model: differences of two q-sparse corruption vectors have support at most 2q. The package checks single deletions only and does not claim an adversarial-error-correction result.
